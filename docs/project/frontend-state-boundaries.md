# 前端状态边界

这份记录用于约束前端状态放置位置，避免后续功能把服务端数据、页面选择和纯 UI 状态混在同一个 store 中。

## Pinia store

Pinia 只保存需要跨路由、跨组件复用，或需要缓存/持久化的状态。

- `dataStore`：服务端健康数据缓存、请求中状态和服务端请求错误。它不保存组件展开、弹窗、表单草稿等纯 UI 状态。
- `dateStore`：日期列表、训练日期集合，以及看板视图模式和日期选择偏好。它可以持久化用户常用选择，但不负责图表渲染细节。
- `filterStore`：筛选选项、筛选请求状态和筛选值。页面只消费筛选结果，不重复维护一份派生选项。
- `authStore`：访问保护配置、鉴权会话状态和认证请求状态。表单输入值仍放在页面本地。
- `themeStore` / `localeStore`：全局展示偏好。组件应通过 composable 或 store 响应变化，避免直接读取 DOM class 作为唯一来源。

## 页面本地状态

只影响当前页面或当前组件实例的状态保留在页面内部，例如导入弹窗开关、选中的导入历史行、密码表单输入、报告周期路由计算值等。

页面本地状态可以调用 store action 获取数据，但不要把一次性弹窗状态写回 Pinia。

## 组件派生状态

图表 option、统计卡片数值、空状态判断和 tooltip 文案属于组件派生状态，优先用 `computed` 或本地函数生成。

ECharts 实例生命周期、窗口 resize 和主题色读取统一走 `useEchartsInstance`，避免每个图表重复维护监听器和 DOM 主题判断。

## 样式边界

- 全局可复用的卡片、图表和页面表面样式放在 `client/src/styles/components.scss`。
- 页面容器结构和标题栏布局放在 `PageContainer` 内。
- 组件局部状态、局部尺寸和内部元素样式保留在组件 scoped 样式中。
- 跨组件深度覆盖只用于第三方组件或明确的插槽边界，优先收敛到公共组件属性或全局组件样式。
