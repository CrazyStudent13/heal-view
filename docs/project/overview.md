# 项目概览

Heal View 是一个面向个人使用的运动健康数据可视化仪表板。它将来自运动健康平台的导出数据整理到本地数据库，通过网页界面提供按日查看、时间趋势、数据对比和睡眠分析。

## 项目目标

- 让个人健康数据脱离单一设备应用，形成可长期保存的记录。
- 用直观图表降低查看历史数据的成本。
- 保持本地优先，减少个人健康数据离开自有环境的需要。
- 为后续更多数据源、报告和指标扩展留下稳定结构。

## 项目边界

Heal View 是数据整理和可视化工具，不是医疗诊断系统。它不替代医生建议，也不会根据图表结果给出医学结论。
