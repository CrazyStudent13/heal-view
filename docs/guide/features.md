# 项目功能

## 当前已实现

- **健康看板**：按日期查看日运动概览和健康指标。
- **单日视图**：查看单日步数、卡路里、心率、睡眠、血压、压力、体重和运动记录。
- **多日对比**：按日期范围比较趋势和统计指标。
- **睡眠分析**：展示夜间睡眠时间轴、深睡、浅睡、REM、清醒阶段及阶段占比。
- **数据导入**：支持运动健康归档数据导入，并在导入前预览解析结果。
- **运动计划**：编排训练计划、训练阶段和每日训练单元，按周月日历查看安排，并在阶段结束后填写一次反馈。计划不只有一个状态：生命周期（草稿、进行中、已结束）由日期推导，达成度按打卡口径由训练单元和导入记录推导，两者分开展示，见[训练计划待办](/todos/training-plan#计划的两个维度)。
- **有氧自动匹配**：按日期和运动类型把导入的运动记录对应到有氧训练项目，给出达标、部分达标、无数据或无法验证的结论，同时展示数据覆盖率和可验证完成率。
- **手机端今日训练**：在 `/m/today` 逐项确认力量训练的实际组数、次数、重量、跳过原因和身体反应。
- **个人配置**：配置访问保护密码，查看项目说明和 GitHub 地址。
- **亮暗主题与中英文**：界面支持主题切换和中文、英文显示。

## 页面状态

周报/月报模块暂时隐藏，待具体需求和验收标准明确后再恢复入口。运动计划的实现范围和后续方向记录在[训练计划待办](/todos/training-plan)中。
