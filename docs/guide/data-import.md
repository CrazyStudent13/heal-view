# 数据导入

## 导入流程

1. 启动前端和后端服务。
2. 打开应用中的“数据导入”页面。
3. 选择运动健康平台导出的归档压缩包。
4. 等待系统解析并检查预览结果。
5. 确认后写入本地 SQLite 数据库。

导入完成后，返回健康看板即可按日期查看数据。

## 数据存储

应用数据默认保存在服务端的 SQLite 文件中。个人部署时建议将数据库文件放在持久化目录，并定期备份。

## 注意事项

- 运动健康导出文件通常包含个人敏感信息，请妥善保管原始压缩包和数据库文件。
- 导入期间不要重复提交同一份大文件。
- 如果解析结果异常，保留错误信息和原始文件，便于后续定位兼容性问题。
