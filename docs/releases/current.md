# 当前版本

## `1.0.0`

当前项目版本为 `1.0.0`，核心目标是完成个人运动健康数据的导入、存储和可视化基础闭环。

### 已包含

- 健康看板和日期浏览
- 单日健康指标展示
- 多日趋势与数据对比
- 睡眠时间轴和睡眠阶段分析
- 运动记录与运动统计
- 体重、心率、血压和压力相关图表
- 小米、华为等运动健康归档数据导入基础能力
- 运动计划编排、训练阶段、每日训练单元和阶段反馈
- 计划的生命周期（草稿、进行中、已结束，由日期推导）与达成度（打卡口径的六档评价，加练计为补充履约）两个维度分开呈现
- 有氧训练项目的导入数据自动匹配、数据覆盖率和可验证完成率
- 手机端今日训练逐项确认
- 个人配置与访问保护
- 中英文和亮暗主题
- 键盘交互、ARIA 语义、图表数据摘要和移动端图表横向浏览
- 前端 ESLint、Prettier、提交前格式化和 GitHub Actions 质量检查
- VitePress 项目文档初版

### 当前限制

- 周报/月报模块暂时隐藏，待具体需求和验收标准明确后再恢复入口。
- 有氧自动匹配目前只核对时长、距离和热量；强度、速度、坡度等指标仍按人工记录处理。
- 同日多条同类运动记录会自动选择最接近目标的一条，人工确认关联入口待后续补充。
- 数据源格式变化时，导入解析器可能需要跟进适配。
- 关键页面截图基线、更多边界测试和真实浏览器行为测试仍待后续需求明确后推进。
