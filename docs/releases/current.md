# 当前版本

## `1.0.0`

当前项目版本为 `1.0.0`，核心目标是完成个人运动健康数据的导入、存储和可视化基础闭环。

### 已包含

- 健康看板和日期浏览
- 单日健康指标展示
- 多日趋势与数据对比
- 睡眠时间轴和睡眠阶段分析
- 运动记录与运动统计
- 体重、心率、血压和压力相关图表
- 小米、华为等运动健康归档数据导入基础能力
- 个人配置与访问保护
- 中英文和亮暗主题
- VitePress 项目文档初版

### 当前限制

- 运动计划页面暂未接入实际计划管理能力。
- 周报、月报页面暂未接入实际报告生成能力。
- 数据源格式变化时，导入解析器可能需要跟进适配。
