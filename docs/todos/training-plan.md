# 训练计划模块待办

这份清单记录 Heal View 训练计划模块的产品约定、第一阶段实现范围和后续扩展方向。模块继续保持单用户、本地优先的定位，不提供医疗诊断或教练服务。

## 产品模型

- **训练计划**：一个长期目标，例如“2026 年减肥计划二期”，包含整体目标、起止日期和状态。
- **训练阶段**：计划中训练方案发生变化的阶段，例如 7-8 月基础训练、9 月恢复训练、10-12 月强化训练。阶段需要支持暂停、顺延、提前结束和调整原因；它不直接承载训练单元。
- **训练单元**：某个具体日期应完成的一整套训练安排，直接关联所属训练计划。
- **训练项目**：训练单元中的单个项目，例如健走、椭圆机、平板支撑或高拉背机。
- **阶段反馈**：训练阶段结束后填写一次，不要求每日手动反馈。

当前计划中的“反馈周期”是阶段结束，而不是固定按月。阶段日期可以跨月，也可以因为手术、身体状态或其他原因顺延。

## 第一阶段：本周目标

目标是完成“计划编排 + 有氧数据验证 + 阶段反馈”的最小闭环。

- [ ] 恢复运动计划入口和页面路由，明确计划列表、当前计划和计划详情的基本布局。
- [ ] 新增训练计划的创建、编辑、暂停、完成和归档流程。
- [ ] 新增训练阶段，支持阶段名称、开始/结束日期、阶段说明、调整原因和状态。
- [ ] 在训练计划内配置每日训练单元，并生成具体日期的训练单元实例。
- [ ] 支持工作日、每日、单日/双日等基础频率规则；复杂自定义规则暂不纳入第一阶段。
- [ ] 为训练项目保存目标时长、距离、组数、次数、重量、速度、坡度等信息；异构目标允许使用结构化 JSON 保存。
- [ ] 仅对有氧训练项目进行导入数据匹配，暂不自动判断力量训练是否完成。
- [ ] 将有氧项目标记为 `auto`，力量项目预留 `manual`，不参与第一阶段自动完成率。
- [ ] 为每日训练单元生成“达标、部分达标、无数据、无法验证”等状态。
- [ ] 区分“没有导入数据”和“训练未完成”，不因数据缺失直接判定失败。
- [ ] 阶段结束后支持填写一次阶段反馈，并展示系统自动汇总的有氧执行情况。
- [ ] 为新增接口、匹配规则和阶段反馈补充基础测试。

## 推荐数据结构

第一阶段建议使用以下业务表：

```text
training_plans
training_phases
training_sessions
training_session_items
training_phase_reviews
```

- `training_plans`：保存整体计划和目标。
- `training_phases`：保存训练方案发生变化的阶段；周期不是简单的计划字段，因为不同阶段可能有不同训练内容。
- `training_sessions`：保存具体日期的训练单元，直接关联训练计划，避免未来修改计划时改变历史安排。
- `training_session_items`：保存训练单元中的单个有氧或力量项目及其目标。
- `training_phase_reviews`：每个训练阶段最多一条正式反馈，记录阶段总结、疲劳、不适、体重变化和调整意见。

阶段结束反馈不要求绑定某一天，也不创建每日反馈表。

## 有氧匹配规则

- [ ] 建立运动类型映射，例如健走、跑步机行走、椭圆机和划船机的设备分类映射。
- [ ] 优先按日期和运动类型匹配；同日多条记录时选择最接近目标的一条或标记为待确认。
- [ ] 按目标时长、距离或卡路里计算达标和部分达标。
- [ ] 对无法匹配的项目显示“无数据/无法验证”，不显示“未完成”。
- [ ] 第一阶段同时展示数据覆盖率和可验证完成率，不合并成一个可能误导的总分。
- [ ] 导入数据清空或重新导入后，确认计划匹配结果能够重新计算，不保留失效的运动记录引用。

## 第二阶段：手机训练页面

第一阶段完成后再增加手机场景，不把每日打卡作为桌面端计划模块的前置条件。

- [ ] 增加适合手机打开的“今日训练”页面。
- [ ] 展示当天训练单元和训练项目，支持训练过程中逐项勾选。
- [ ] 支持记录组数、次数、重量、跳过原因和训练中的不适感受。
- [ ] 新增手动执行记录，与自动导入记录区分来源：`manual` / `auto_import`。
- [ ] 允许手动记录补足无法由手表识别的力量训练。
- [ ] 评估移动端离线草稿和网络恢复后的同步策略。

## 后续扩展

- [ ] 支持更复杂的训练频率和重复模板。
- [ ] 支持有氧与力量训练的混合完成度统计。
- [ ] 支持阶段之间复制训练安排和仅调整未来训练单元。
- [ ] 支持计划版本或阶段快照，保留每次调整前后的差异。
- [ ] 支持将导入运动记录人工确认关联到训练单元。
- [ ] 评估训练阶段完成后的自动复盘和下一阶段调整建议；不输出医疗诊断或风险结论。

## 验收标准

- 可以创建一个包含多个训练阶段的减肥计划。
- 可以为计划生成具体日期的训练单元，并查看当天计划内容。
- 有氧训练有导入记录时可以显示匹配和达标状态。
- 没有导入记录时显示无法验证，不误报为未完成。
- 阶段结束后可以填写一次反馈，并看到该阶段的有氧数据摘要。
- 修改未来阶段不会改变已经结束阶段的历史训练单元和反馈。
