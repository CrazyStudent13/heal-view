# 单日睡眠阶段分析与标题规范方案

## 目标

- 在单日模式的“睡眠时长”页面补充睡眠阶段时长分析。
- 同时展示绝对时长和阶段占比，避免只看时间轴时难以比较。
- 统一页面标题层级：左侧“数据概览”为一级标题，右侧卡片标题为二级标题。
- 保持中英文、亮暗主题和窄屏布局一致。

## 已采用方案

### 数据口径

数据沿用单日睡眠时间轴接口返回的 `segments`，不新增后端请求。每个分段根据 `state`、`startTime` 和 `endTime` 计算分钟数，并按以下四类汇总：

| 阶段 | 字段值 | 颜色 | 统计说明 |
| --- | --- | --- | --- |
| 深睡 | `deep` | `#2A35C0` | 计入实际睡眠 |
| 浅睡 | `light` | `#29B6F6` | 计入实际睡眠 |
| 快速眼动 | `rem` | `#1DE9B6` | 计入实际睡眠 |
| 清醒 | `awake` | `#FFAB00` | 计入在床阶段分布，不计入实际睡眠 |

跨午夜分段使用 `end + 1440 - start` 计算。饼图占比的分母是四类阶段总时长，因此可以同时看到夜间清醒所占比例；深睡、浅睡和快速眼动之和与实际睡眠时长对应。

### 图表方案

- 横向柱状图：比较各阶段绝对时长，标签显示“小时 + 分钟”。
- 环形饼图：比较各阶段占比，保留一位小数。
- 两张图共用时间轴的阶段颜色，悬停提示同时显示时长和占比。
- 760px 以下改为上下排列；宽屏为左右排列。
- 图表监听容器尺寸、当前语言和主题变化并重新布局。

### 标题规范

统一使用 `SectionTitle` 组件，内部由 Element Plus 的 `el-text` 和 `el-icon` 渲染：

| 层级 | 使用位置 | 语义标签 | 字号/字重 |
| --- | --- | --- | --- |
| 一级 | 左侧“数据概览” | `h1` | 20px / 600 |
| 二级 | 右侧卡片、图表和信息区 | `h2` | 16px / 600 |

标题统一使用左对齐、标准字距和主题文字颜色。图标为可选插槽，统一使用主题主色。

### 页面结构

单日睡眠页按以下顺序组织：

1. 睡眠概览卡：总睡眠、平均心率、中断次数。
2. 睡眠时间段：阶段时间轴和心率趋势。
3. 睡眠阶段时长分析：横向柱状图和环形饼图。

没有分段数据时维持原有空状态或多日睡眠图表回退逻辑，不展示无意义的阶段分析。

## 响应式与主题

- 900px 以下：左侧概览移动到图表上方，概览项使用两列网格。
- 520px 以下：概览项改为单列。
- 760px 以下：睡眠柱状图和饼图改为上下排列。
- 600px 以下：顶部日期控件允许收缩并独占一行。
- 图表颜色从 CSS 主题变量读取；切换亮暗主题时更新坐标轴、提示框、文字和分隔线。

## 备选与后续方案

### 方案 A：前端按时间轴分段汇总（当前采用）

优点是无需修改接口，图表和时间轴使用同一份数据，交付范围小。适合当前单用户、单日分析场景。

### 方案 B：使用每日汇总字段

可直接使用 `deepSleepHours`、`lightSleepHours` 和 `remSleepHours`，但缺少可靠的清醒阶段字段，且无法保证与时间轴分段完全一致。适合作为时间轴接口不可用时的降级展示。

### 方案 C：后端返回阶段聚合结果

后端在睡眠时间轴响应中增加 `stageDurations` 和 `stagePercentages`。当客户端增多、统计规则需要统一或数据量扩大时采用，可以避免各端重复实现跨午夜和异常分段处理。

### 可继续扩展

- 增加睡眠效率：实际睡眠时长 / 在床总时长。
- 增加阶段参考区间，但需要明确年龄、设备算法和医学口径。
- 支持点击柱形或饼块联动高亮时间轴中的对应阶段。
- 将睡眠阶段统计抽为共享工具，并为跨午夜、缺失字段和异常时间增加单元测试。

## 验收清单

- 单日模式选择有睡眠分段的日期后，两张图正常显示四个阶段。
- 柱状图时长之和与饼图统计总时长一致。
- 左侧标题为 `h1`，右侧卡片标题为 `h2`。
- 中英文、亮色和暗色主题下文字与图表均可读。
- 1024px、760px 和 390px 宽度下无横向溢出、标题遮挡或图表重叠。
